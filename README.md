# 帆船赛现场控制和申诉处理

源提示词摘要：竞赛官维护组别、航线、起航时间和处罚记录，计时员提交到达数据，裁判处理抗议、重赛、弃权和成绩更正；冲突或重复处罚进入复核，操作保留时间线。

## 技术栈

React 19、TypeScript、Vite、Ant Design、Redux Toolkit、RTK Query、React Router、React Hook Form、Zod、i18next。

## 本地运行

```bash
npm install
npm run dev
```

开发端口：`62024`

## 可用流程

- 竞赛控制：按“场次 + 航次”追加登记正常起航、个别召回、一般召回和黑旗；冲突事件按发生/接收时间合并，晚到记录不会覆盖已确认起航。
- 一般召回：只让该场未起航船的到达成绩失效；已确认起航船的成绩继续保留。
- 黑旗处罚：处罚不落在当前场，而是自动顺延到后续第一个有效场次；原场次取消或裁判改判会撤销原处罚并立即重算名次。
- 成绩管理：按场次登记到达；正式成绩发布后冻结，之后的改判自动形成新版本，普通到达不能覆盖正式结果。
- 申诉处理：提交抗议、进入复核、支持或驳回；裁判撤销起航/黑旗后，事件时间线保留全部依据。
- 离线终端：断网时事件进入本地 outbox，恢复后按原发生时间重放到原场次；事件 ID 幂等，重复同步不会重复记罚。
- 数据使用 localStorage v2 持久化，刷新页面后继续保留；旧版数据不会迁移到新的事件模型。
